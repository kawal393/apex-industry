# APEX PSI — INDUSTRY DOOR (apex-industry)

One of the four specification doors of **Apex PSI — Universal Verification Protocol**,
the open verification layer for the AI economy.

- Canonical declaration: https://ai-governance-standard.com/declaration
- Verification is free forever (MIT).
- IETF drafts are individual submissions, not formally endorsed.
- Verify everything yourself.

**Status:** open standard under active development. Specification drafts land here as they mature.
